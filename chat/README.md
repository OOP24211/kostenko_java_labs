\# Чат на Java (WebSocket + JavaFX + PostgreSQL)



Реальное время: многопользовательский чат с комнатами, авторизацией, историей сообщений и созданием новых комнат.



\##  Возможности



\-  Регистрация и вход пользователей

\-  Создание и переключение между текстовыми комнатами

\-  Отправка сообщений в реальном времени через WebSocket

\-  Сохранение истории сообщений в PostgreSQL



\## 🛠️ Технологии



| Компонент      | Технология                          |

|----------------|-------------------------------------|

| Клиент         | Java 11+, JavaFX, WebSocketClient   |

| Сервер         | Java-WebSocket, многопоточность     |

| База данных    | PostgreSQL                          |

| Сериализация   | Gson                                |

| Сборка         | Maven
