\# CSV Word Counter



A lightweight Java application that analyzes text files, counts word frequencies, and exports the results to CSV format.



\## Description



This tool reads a text file, splits it into words, counts how many times each word appears, sorts them from most to least frequent, and saves the result as a CSV file.



\## Features



\- Supports English and Russian characters

\- Case-insensitive (converts all words to lowercase)

\- Sorted by frequency (highest first)

\- Outputs to CSV format

\- Simple command-line interface



\## How to Use



\### Compile:

```bash

javac csvparser/\*.java

```



\### Run:

```bash

java csvparser.Main input.txt output.csv

```
