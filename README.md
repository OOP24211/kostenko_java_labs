# Автосервис "Razval"

**Веб-приложение для записи автомобилей на сервисное обслуживание**



## Описание проекта

Проект представляет собой веб-приложение для автосервиса, где пользователи могут:

* Зарегистрироваться и войти в систему
* Добавлять свои автомобили в личный кабинет
* Просматривать список услуг и цены
* Записываться на обслуживание (выбор услуги, даты, времени)
* Просматривать и отменять свои записи



## Технологии

|Технология|Назначение|
|-|-|
|Java|Основной язык|
|Spring Boot|Веб-фреймворк|
|Spring Security|Авторизация и защита|
|Spring Data JPA|Работа с БД|
|PostgreSQL|База данных|
|Thymeleaf|Шаблонизатор HTML|
